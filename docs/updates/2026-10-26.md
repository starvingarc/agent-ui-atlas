## Preview contract / 预览字段

`previews` is an optional additive field on styles and skills. Each item records an HTTPS `url`, bilingual `label`, `kind`, and ISO-date `checked_on`. Top-level `preview_hubs` provides browsing entry points. Existing schema version 1 resource fields and IDs are retained.

| Kind | Meaning |
|---|---|
| `interactive_demo` | Controls or a theme editor are offered / 提供控件或主题编辑器 |
| `showcase` | A visual example or gallery / 效果示例或画廊 |
| `live_site` | The current real website, which can evolve independently of the spec / 当前真实网站，可能与历史规范不同 |

`checked_on` records link/content review, not exhaustive functional verification. Preview URLs do not replace canonical specifications. A missing preview does not establish that no public demo exists.
