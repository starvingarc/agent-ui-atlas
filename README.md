# Agent UI Atlas

**English** · [简体中文](README.zh-CN.md)

A curated atlas of UI design languages and style references for AI agents. It turns a collection of design resources into direct, human-readable style choices such as **Apple**, **Linear**, **Animal Crossing**, or **Stardew Valley-inspired pixel art**.

> Last reviewed: **2026-07-16**
> Seeded from the public GitHub Stars and Forks of [starvingarc](https://github.com/starvingarc).
> Current snapshot: **104 UI/reference styles**, **16 image-layer styles**, and **3 motion-layer styles**.

## How to Use

1. Pick a style from the tables below.
2. Copy its **Agent Invocation** into your coding or design agent.
3. Open the upstream source when the agent needs the full design specification, skill, prompt, or reference implementation.
4. Combine one UI style with at most one image layer and one motion layer when needed.

Example:

> Design with Apple: generous whitespace, SF-style typography, cinematic product imagery. Add Apple Fluid Motion, but keep the interaction restrained.

## Availability

Only these availability values are used:

- **DESIGN.md** — a ready-to-read design system document for agents.
- **Agent Skill** — installable or copyable agent instructions.
- **Prompt/Component Library** — a reusable prompt, component set, or visual prompt collection.
- **Reference Implementation** — a distinctive working interface to study or reproduce.
- **Background Theme** — a scene or background direction, not a complete UI system.

## Curation Policy

- **Style-first:** each row represents a visual language, not merely a repository.
- **Direct naming:** recognizable brand or IP names are preferred over obscure taxonomy.
- **Evidence-based:** every row links to an upstream specification, skill, prompt library, theme definition, or working implementation.
- **Deduplicated:** equivalent styles share one row and may retain multiple upstream sources.
- **Upstream-only links:** personal forks are not used as canonical sources.
- **UI scope:** ordinary agent tools, generic component libraries, and presentation-only styles are excluded.
- **Manual maintenance:** this first version is personally maintained and does not yet accept submissions.
- **No embedded previews yet:** screenshots may be added later after provenance and licensing are reviewed.
